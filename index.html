THE BIG PICTURE

Git versus GitHub

LOCAL TOOL

Git

A version control system that tracks file changes and lets you revisit earlier versions on your computer.

ONLINE PLATFORM

GitHub

A hosting and collaboration platform for Git repositories, with issues, pull requests, reviews, and GitHub Pages.

TEAMWORK

Working together

Everyone can work in a separate branch, discuss proposed changes, and merge reviewed work into the main project.

Remember: A commit saves a snapshot locally. A push uploads commits to a remote repository. A pull gets remote updates and integrates them into your current branch.
